# preference_change

Prototype software accompanying the paper:

**Theofanis Aravanis**, “A relational framework for preference change”, *Logic Journal of the IGPL*, Vol. 34, No. 1, February 2026, article jzag003. DOI: 10.1093/jigpal/jzag003.

The paper introduces a language-agnostic, relational framework for modelling preference change. Preferences are represented as preorders over a finite set of items, and preference revision and contraction are defined directly on these relations using set-theoretic operations and closure conditions.

This repository contains the prototype application described in the paper. The application implements the proposed preference-change policies using Answer Set Programming (ASP) and provides a graphical interface for computing revised or contracted preference relations.
