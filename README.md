# preference_change
An Applied Framework for Preference Change

This executable implements a framework for modeling rational preference dynamics using a descriptive set-theoretic approach. It allows users to represent agent preferences as preorders over a set of items and apply revision or contraction operations without relying on formal logic syntax. The system includes a graphical interface and leverages Answer Set Programming (ASP) to compute and visualize preference changes, making it suitable for research in decision theory, AI, and rational agent modeling.
